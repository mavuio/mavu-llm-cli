Issues are tracked in GitHub Issues for `mavuio/filmarchiv_ex`; external PRs are not a triage surface. See `docs/agents/issue-tracker.md`.

Use the canonical triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.
